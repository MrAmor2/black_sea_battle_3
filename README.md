# Морской бой на Чёрном море

## Описание репозитория

Главным файлом программы является `sea_battle.cpp`, в котором непосредственно выполняются функции из остальных файлов 
 
Остальные файлы содержат одноимённые функции: 
- `get_coordinates.cpp` - принимает на вход от пользователя 10 пар координат в формате *буквачисло* (например, *a1 a3*), 
каждая пара задаёт расположение корабля на поле; в функции производится проверка корректности ввода; 
функция возвращает массив из тех же координат, но в формате чисел для дальнейшего удобного использования 
 
- `fill_list_of_ships.cpp` - заполняет массив из 10 массивов, в каждом из которых содержатся координаты всех палуб корабля 
 
- `check_board.cpp` - осуществляет проверку корректного расположения кораблей на поле 
 
- `make_board.cpp` - создаёт доску игрока с расположением его кораблей на поле 
 
- `draw_boards.cpp` - выводит доску для атаки поля соперника, а также возможен вывод собственной доски игрока 
 
- `make_move.cpp` - реализует ход игрока, принимает на вход от пользователя координаты для нанесения удара 
 
В папке `include` содержатся head-файлы для подключения описанных выше файлов в `sea_battle.cpp` 
 
В файле `CMakeLists.txt` находятся настройки сборки проекта
