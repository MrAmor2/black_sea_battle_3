# Морской бой на Чёрном море

## Описание репозитория

Главным файлом программы является `sea_battle.cpp`, в котором непосредственно выполняются функции из остальных файлов. 
 
В папке `src` находятся остальные `*.cpp` файлы, реализующие, как правило, одноимённые функции: 
 
- `get_coordinates.cpp` - получает от пользователя 10 пар (то есть всего 20) крайних координат кораблей с помощью клавиш, 
заполняет ими массив в удобном формате, осуществляя проверку корректности ввода; 
 
- `print_rules.cpp` - выводит правила и обозначения морского боя;

- `mini_functions.cpp` - содержит две маленькие функции, одна из которых перемещает курсор, а другая выводит символ unicode 
по значению char; 
 
- `make_board.cpp` - создаёт доску игрока с расположением его кораблей на поле и после окончания ввода заполняет массив 
из 10 массивов, в каждом из которых содержатся координаты всех палуб корабля; 
 
- `draw_boards.cpp` - выводит доску для атаки поля соперника, а также возможен вывод собственной доски игрока; 
 
- `make_move.cpp` - реализует ход игрока, принимает на вход от пользователя координаты для нанесения удара через клавиши. 
 
В папке `include` содержатся head-файлы для подключения в `sea_battle.cpp` описанных выше файлов. 
 
В файле `CMakeLists.txt` находятся настройки сборки проекта. 

## Запуск проекта

Для запуска проекта необходимо последовательно ввести в терминале следующие команды:
 ```
 mrdir build
 cd build
 cmake ..
 make
 ./sea_battle
 ```

 Примечание: для корректного отображения данных на экране рекомендуется не скроллить терминал.
